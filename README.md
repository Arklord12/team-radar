# Team Radar

Aplicación de evaluación de equipos creada con React y Vite.

## Ejecutar en tu computadora

Instala Node.js 20.19 o posterior (o 22.12 o posterior) y ejecuta en esta carpeta:

```sh
npm install
npm run dev
```

Abre en el navegador la dirección local que muestra Vite. No abras `index.html` directamente: el navegador necesita que Vite procese el código React y sus dependencias.

## Publicar en GitHub Pages

En el repositorio, abre **Settings → Pages** y selecciona **GitHub Actions** como fuente. El flujo de trabajo compila y publica la aplicación cuando se actualiza la rama `main`. Puedes consultar su estado en **Actions**. La dirección prevista es https://arklord12.github.io/team-radar/.
