# team-radar
Herramienta web desarrollada para la evaluación cruzada de equipos de trabajo, pensada para estructurar evaluaciones en asignaturas como Dirección Empresarial. Permite a un usuario calificar a sus compañeros y a sí mismo en múltiples valores predefinidos, visualizando el balance del equipo en un gráfico de radar y exportando un reporte detallado.
